# BlogSpace – Full Stack Blog Application

## About
BlogSpace is a full-stack blogging application
where users can register, log in, create,
edit, view and delete blog posts.

## Technologies Used
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Git and GitHub

## Features
- User Registration
- User Login
- JWT Authentication
- Create Blog
- View Blog
- Edit Blog
- Delete Blog
- Responsive Design

## Project Structure
- Frontend
- backend

## Installation

1. Clone the repository.
2. Install backend dependencies.
3. Configure the .env file.
4. Start the backend server.
5. Open the frontend using Live Server.

## Environment Variables
PORT
MONGO_URI
JWT_SECRET
CLIENT_URL
